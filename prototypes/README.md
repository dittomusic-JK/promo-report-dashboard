# Prototypes

Self-contained HTML mocks for the next Promo client products. Fonts, logos and imagery are embedded, so each file opens on its own.

- `social-handbook.html` — the client-facing Social Handbook (living 4/6-week Instagram + TikTok plan, tick-off, move, add-to-calendar, guide modules).
- `handbook-builder.html` — the staff builder (campaign setup, hero image fallback chain, drag-and-drop calendar fed by the idea library, guide modules, client activity).

Serve the folder with the `prototypes` entry in `.claude/launch.json`, or open the files directly.
